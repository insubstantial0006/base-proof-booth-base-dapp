# Base Proof Booth

## App Name

Base Proof Booth

## Tagline

Print your proof

## Description

Print a short statement on Base and keep a clean receipt that shows who said it and when.

Character count: 90

## Category

Proof / statement / onchain utility

## Short Pitch

Base Proof Booth gives people a simple way to print one public statement and keep a timestamped proof receipt on Base.

## Production Environment Variables

- `NEXT_PUBLIC_PROOF_BOOTH_CONTRACT_ADDRESS`: deployed proof booth contract address
- `NEXT_PUBLIC_BUILDER_CODE`: Base Builder Code after the app is registered
- `NEXT_PUBLIC_BASE_APP_ID`: Base.dev app id for domain ownership verification
